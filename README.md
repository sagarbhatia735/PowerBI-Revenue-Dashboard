# 📊 Subscription & Revenue Performance Dashboard

An end-to-end data analysis project featuring a custom Python data generator, SQL database schema, and an interactive Power BI dashboard tracking monthly recurring revenue, plan subscriptions, and high-level KPIs.

![Dashboard Preview](Subscription%20%26%20Revenue%20Performance%20Dashboard.png)

---

## 🎯 Project Overview
This project answers three key business questions:
1. **High-Level Metrics:** What are our total payments, monthly revenue baseline, and subscriber counts?
2. **Revenue Trends:** How does revenue fluctuate across months (January–December)?
3. **Plan Breakdown:** Which subscription tier (Enterprise, Pro, Basic) drives the highest revenue?

---

## 🛠️ Tech Stack & Tools
* **Python (Pandas):** Automated data generation (`main.py`) and CSV exports.
* **SQL / SQLite:** Database creation and relational schema design (`saas_data`).
* **Power BI:** Data visualization, interactive dashboard design, and UI formatting (`Subscription & Revenue Performance Dashboard.pbix`).

---

## 📈 Key Insights
* **Peak Revenue:** Revenue hit its highest point in **February ($13.1K)** before experiencing a mid-year dip in **July ($4.4K)**.
* **Top Performing Plan:** **Enterprise** generated the highest revenue ($45K), followed by **Pro** ($34K) and **Basic** ($15K).
* **Subscriber Scale:** Active user base stands at **1,000 subscribers** with **$2M** in lifetime payments processed.
